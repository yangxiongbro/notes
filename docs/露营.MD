# 帐篷

**帐篷的面料分为外账面料、内账面料、底帐面料三个部分。**

- **外账面料**：市面上主流的外账面料有[PU涂层](https://zhida.zhihu.com/search?content_id=707433710&content_type=Answer&match_order=1&q=PU涂层&zhida_source=entity)、[涂硅尼龙](https://zhida.zhihu.com/search?content_id=707433710&content_type=Answer&match_order=1&q=涂硅尼龙&zhida_source=entity)、[粗苯纤维](https://zhida.zhihu.com/search?content_id=707433710&content_type=Answer&match_order=1&q=粗苯纤维&zhida_source=entity)三种，**其中粗苯纤维重量最轻、强度最高、防水效果更好**，就算意外破损，也可以用胶带快速修补；**在预算有限的情况下，可以选PU涂层，防水耐用经济实惠。**

- **内账面料**：内账面料通常用透气性良好的面部和尼龙绸，**建议优先选择尼龙绸，易干不易发霉。**

- **帐底面料**：帐底面料一般有聚乙烯材料（PE）、聚氯乙烯（PVC）、聚氨酯（PU）涂层的[牛津布](https://zhida.zhihu.com/search?content_id=707433710&content_type=Answer&match_order=1&q=牛津布&zhida_source=entity)这三种，可以有效防止雨水渗透进入帐篷内，保证帐篷内地面干燥、整洁，**建议优先选择聚氨酯（PU）涂层的牛津布，耐寒、兼顾、防水性能都很棒，冬天不建议选择PVC。**
