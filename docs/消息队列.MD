# Kafka

## Spring Boot 集成



在 Spring Boot 中消费 Kafka，主要通过 **`spring-kafka`** 依赖和 **`@KafkaListener`** 注解实现。下面是一套完整的实践指南。

---

### 一、添加依赖

```xml
<dependency>
    <groupId>org.springframework.kafka</groupId>
    <artifactId>spring-kafka</artifactId>
</dependency>
```

Spring Boot 会自动配置 `KafkaTemplate`、`ConsumerFactory`、`KafkaListenerContainerFactory` 等。

---

### 二、基础配置（application.yml）

```yaml
spring:
  kafka:
    bootstrap-servers: localhost:9092
    consumer:
      group-id: my-group
      auto-offset-reset: earliest          # 无 offset 时从最早开始
      enable-auto-commit: false            # 建议手动提交
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      value-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      max-poll-records: 500                # 一次拉取最大条数
      properties:
        session.timeout.ms: 10000
        max.poll.interval.ms: 300000
    listener:
      ack-mode: manual_immediate           # 手动立即提交
      concurrency: 3                       # 并发消费者数，不超过分区数
```

---

### 三、基础消费者示例

```java
@Component
public class OrderConsumer {

    @KafkaListener(topics = "orders", groupId = "my-group")
    public void consume(String message) {
        System.out.println("收到消息：" + message);
    }
}
```

如果需要更细粒度控制，可以接收 `ConsumerRecord`：

```java
@KafkaListener(topics = "orders", groupId = "my-group")
public void consume(ConsumerRecord<String, String> record) {
    System.out.println("topic=" + record.topic() 
        + ", partition=" + record.partition()
        + ", offset=" + record.offset()
        + ", key=" + record.key()
        + ", value=" + record.value());
}
```

---

### 四、手动提交 Offset

配置 `enable-auto-commit: false` 和 `ack-mode: manual_immediate`，然后在监听方法中注入 `Acknowledgment`：

```java
@KafkaListener(topics = "orders", groupId = "my-group")
public void consume(String message, Acknowledgment ack) {
    try {
        // 业务处理
        process(message);
        // 处理成功，手动提交
        ack.acknowledge();
    } catch (Exception e) {
        // 处理失败，不提交，等待重试或进入死信
        log.error("消费失败", e);
    }
}
```

**注意**：`ack-mode` 常用值：

- `RECORD`：每条记录处理完提交一次（默认）
- `BATCH`：一批处理完提交一次
- `MANUAL` / `MANUAL_IMMEDIATE`：手动调用 `ack.acknowledge()` 提交

---

### 五、批量消费

配置 `batch-listener: true` 和 `max-poll-records`，监听方法接收 `List`：

```yaml
spring:
  kafka:
    listener:
      type: batch
      ack-mode: manual_immediate
```

```java
@KafkaListener(topics = "orders", groupId = "my-group")
public void consumeBatch(List<String> messages, Acknowledgment ack) {
    for (String msg : messages) {
        process(msg);
    }
    ack.acknowledge();
}
```

### 六、JSON 反序列化

配置消费者 value 反序列化为 JSON：

```yaml
spring:
  kafka:
    consumer:
      value-deserializer: org.springframework.kafka.support.serializer.JsonDeserializer
      properties:
        spring.json.trusted.packages: com.example.dto
        spring.json.value.default.type: com.example.dto.Order
```

监听方法直接接收对象：

```java
@KafkaListener(topics = "orders", groupId = "my-group")
public void consume(Order order) {
    System.out.println(order);
}
```

### 七、错误处理与重试

#### 1. 默认重试

```yaml
spring:
  kafka:
    listener:
      retry:
        max-attempts: 3
        backoff:
          interval: 1000
          multiplier: 2
```

#### 2. 自定义错误处理器

```java
@Bean
public DefaultErrorHandler errorHandler(KafkaTemplate<String, String> template) {
    DeadLetterPublishingRecoverer recoverer = 
        new DeadLetterPublishingRecoverer(template);
    return new DefaultErrorHandler(recoverer, new FixedBackOff(1000L, 3));
}
```

消费失败超过重试次数后，消息会发送到死信 Topic（默认 `原topic.DLT`）。

#### 3. 幂等消费

Kafka 只保证 **至少一次** 投递，重复消费无法完全避免。业务层需保证幂等：

- 唯一业务 ID + 数据库唯一索引
- Redis `setIfAbsent` 去重
- 状态机控制流转

---

### 八、并发消费

```yaml
spring:
  kafka:
    listener:
      concurrency: 3   # 启动 3 个消费者线程
```

**并发数不能超过分区数**，否则多出的线程空闲。增加并发需先增加 Topic 分区数。

---

### 九、常见问题

| 问题           | 原因                   | 解决                                              |
| -------------- | ---------------------- | ------------------------------------------------- |
| 重复消费       | 自动提交 offset 前失败 | 手动提交 + 幂等                                   |
| 消息丢失       | 自动提交后业务失败     | 关闭自动提交，处理完再提交                        |
| 消费积压       | 消费者处理慢           | 增加分区和并发、优化业务、批量消费                |
| 反序列化失败   | 类型不匹配             | 配置正确的 Deserializer 和 trusted packages       |
| Rebalance 频繁 | 心跳超时或处理超时     | 调整 `session.timeout.ms`、`max.poll.interval.ms` |

### 十、完整示例

```java
@Configuration
public class KafkaConfig {

    @Bean
    public ConcurrentKafkaListenerContainerFactory<String, String> kafkaListenerContainerFactory(
            ConsumerFactory<String, String> consumerFactory) {
        ConcurrentKafkaListenerContainerFactory<String, String> factory =
                new ConcurrentKafkaListenerContainerFactory<>();
        factory.setConsumerFactory(consumerFactory);
        factory.setConcurrency(3);
        factory.getContainerProperties().setAckMode(ContainerProperties.AckMode.MANUAL_IMMEDIATE);
        factory.setCommonErrorHandler(new DefaultErrorHandler(new FixedBackOff(1000L, 3)));
        return factory;
    }
}
```

```java
@Component
public class OrderConsumer {

    @KafkaListener(topics = "orders", groupId = "my-group")
    public void consume(ConsumerRecord<String, String> record, Acknowledgment ack) {
        try {
            // 幂等业务处理
            process(record.value());
            ack.acknowledge();
        } catch (Exception e) {
            log.error("消费失败，offset={}", record.offset(), e);
            // 不提交，等待重试或进入死信
        }
    }
}
```

---

**一句话总结**：Spring Boot 消费 Kafka 用 `@KafkaListener` + `spring-kafka`，生产环境建议 **手动提交 offset + 并发消费 + 错误重试 + 死信队列 + 业务幂等**，保证不丢不重。
